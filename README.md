# ML Engineering Journey

## About

I am a 7th-semester BS Artificial Intelligence student documenting my practical journey towards becoming an ML Engineer.

This repository serves as a record of my learning, experiments, practice exercises, and projects as I develop the technical and engineering skills required for a career in Machine Learning Engineering.

## Goals

- Strengthen programming and problem-solving skills.
- Develop proficiency in Python and its data science ecosystem.
- Understand data manipulation and numerical computing.
- Learn Machine Learning concepts and their practical applications.
- Develop software engineering skills and workflows required for ML Engineering.
- Build practical projects that demonstrate my abilities.

## Repository Structure

This repository is organized into different folders based on the technologies and concepts I learn.

- `00-engineering-tools/` – Engineering tools and workflows, including Git and GitHub.
- `01-python/` – Python practice, programming concepts, and problem-solving.
- `02-numpy/` – Numerical computing and NumPy exercises.
- `03-pandas/` – Data manipulation and analysis using Pandas.
- `04-machine-learning/` – Machine Learning concepts and experiments.
- `05-ml-projects/` – Practical projects combining the skills I develop.
